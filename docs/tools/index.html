GHOST / tools

Five tools, one contract.

Signatures and return shapes below are taken from the served code (server/ghost_http_server.py, server/ghost_server.py) — not from documentation that could drift.

The 4-step contract

One loop, closed by grounding. Every outcome you report widens the regime where GHOST can answer.

01 · preflight_patch

Free deterministic checks

git-apply, py_compile, rewrite detection. Zero tokens — run first.

02 · risk_scan

Goal-free attractor score

Returns low_risk / high_risk / abstain + a call_id.

03 · your tests

Run them

No tool replaces executing your tests. Ever.

04 · report_outcome — the measured outcome and its method. Self-declared opinions are rejected from reinforcement.

risk_scan — the goal-free verdict

risk_scan(state_text: str, diff_text: str, exclude_task: str = "",
          reporter: str = "") -> str

The ghost of every past run grades your diff draft: distance to the nearest past failure minus distance to the nearest past success (failure-attractor, goal-free — no gold text required). A verdict is rendered only inside the conformal regime (per-stratum error guarantee ≤10%, realized 9.1%); everywhere else the answer is abstain — the ghost stays silent when it does not know. exclude_task removes a task from the pool (anti-leak); reporter is your agent identity, used to stratify reinforcement.

# returns
# { "decision": "high_risk",            low_risk / high_risk / abstain
#   "attractor_score": -0.2423,         d(nearest fail) − d(nearest pass)
#   "confidence": 0.2358, "tau": 0.1392,
#   "family": { "nearest_family": "…", "coverage": { "n": 6, "positives": 2 } },
#   "call_id": "3b11700f69f3" }          → report_outcome after your tests

preflight_patch — the free tier

preflight_patch(repo_path: str, diff_text: str,
                state_files: list[str] | None = None) -> str

Deterministic checks before any execution: git apply --check (malformations, paths), py_compile of the patched result (syntax), then a reverse-apply to leave the repo untouched. Zero LLM tokens — this is the tool to call before investing in a test run.

# returns
# { "ok": true,
#   "checks": { "apply": true, "compile": { "mod.py": true } },
#   "call_id": "9c41d2e07b2a" }
# on failure: "apply_err" / "compile_err" carry the tool stderr (last 400 chars)

report_outcome — close the loop

report_outcome(call_id: str, passed: bool, reporter: str = "",
               grounded_by: str = "") -> str

Journals the real outcome of an evaluated patch — a grounded result from execution, never the model's opinion. grounded_by names the measurement method (pytest-f2p, ci, human). Outcomes without a method are rejected from reinforcement. Pairs with the scan by call_id for the nightly flywheel.

# returns
# "enregistré"

near_mis_patches — evidence, not vibes

near_mis_patches(state_text: str, diff_text: str, goal_text: str,
                 k: int = 3) -> str

The k nearest pool patches in latent space, with their actual execution outcome (pass/fail) — to inform a choice instead of rendering a verdict. Neighbours are deduplicated by task: if two top hits are the on/off arms of the same task, only one is kept.

# returns
# { "call_id": "…", "nearest": [
#     { "task": "…", "arm": "on", "family": "…", "y": 1, "sim": 0.87 }, … ] }

assess_patch — the gold axis

assess_patch(state_text: str, diff_text: str, goal_text: str) -> str

Harness / evaluation mode only: goal-bound latent energy — it requires the goal text, which is unavailable in production. Advisory, like everything else here. Its calibration (predictor-mcp-calibration.json) is documented on the calibration page.

The ghost of every past run grades your patch draft. Goal-free, calibrated, advisory. An instrument of the Latent Imagination measurement project.
