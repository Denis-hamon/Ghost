GHOST / calibration

The numbers, as served.

The currently served pool is v12 — its conformal calibration is rendered verbatim below from the measurement project's sealed governance artifacts. The v8 artifacts still ship in this repository (artifacts/) and are kept for comparison: every number on this page comes from an artifact, not from copy.

Why a regime, not a score

A verdict without a measured regime is indistinguishable from a guess.

instrumentglobalreliable regime
risk_scan (goal-free)ext-LOAO AUC 0.708, CI95 [0.635, 0.775] on the certifiable population (211 rows) — a rank, not a verdict realized error 9.1% (guarantee ≤10% per stratum, α = 0.10) on the ~10% of queries it answers
everything else—abstain

GHOST refuses to dress the global rank up as a verdict. Inside the regime, the answer comes with a measured accuracy; outside it, the answer is abstain with the nearest pool family and its coverage — which is itself the signal for where the pool must grow.

risk-scan v12 — the conformal calibration, currently served

governance/act2/arm-artifacts/risk-scan-v12-conformal.json (measurement project, generated 2026-08-17), key fields verbatim:

{ "story": "12.1-conformal-mondrian",
  "pool": "latent-pool-v12", "pool_sha256_16": "271c651bc053aa45",
  "n_rows": 430, "positives": 205, "thr_pool": -0.003279,
  "v6_positive_control": { "expected": [0.822, 0.779], "got": [0.822, 0.779], "ok": true },
  "global_conformal": {
    "alpha_0.05": { "tau": 0.273575, "kept": 27, "realized_err_rate": 0.037,
                    "wilson95": [0.0066, 0.1828], "coverage_share": 0.0628 },
    "alpha_0.10": { "tau": 0.217081, "kept": 44, "realized_err_rate": 0.0909,
                    "wilson95": [0.0359, 0.2116], "coverage_share": 0.1023 } } }

How to read it: for each registered α, τ is the smallest confidence bar such that the error rate of kept answers (leave-one-out replay, per Mondrian stratum) stays ≤ α — a guarantee under intra-stratum exchangeability, with the finite-sample Wilson interval disclosed rather than hidden. At α = 0.10 the server answers ~10% of queries with a realized error of 9.1%; strata with fewer than 12 rows get no τ at all and always abstain. The v6 positive control (expected = got) guards the pipeline against silent regressions.

risk-scan v8 — shipped in this repository

artifacts/risk-scan-v8-calibration.json, verbatim — the previous serving calibration, kept for comparison:

{ "pool": "latent-pool-v8.json",
  "n": 207, "positifs": 73, "majority": 0.6473,
  "recipe": "score = d(nearest fail) - d(nearest pass), LOAO F1;
             thr = médiane pool figée; conf = |score - thr|",
  "thr_pool": -0.006551,
  "tau_10pct": 0.139247,
  "predict_regime": {
    "coverage": 0.1, "n": 21,
    "acc_measured_serving_recipe": 0.952381,
    "wilson95": [0.7733, 0.9915],
    "acc_measured_LOAO": 0.952,
    "note": "pred si conf>=tau_10pct, sinon abstain" } }

How to read it: the attractor score of a query is compared to thr_pool (the frozen pool median); the distance between the two is the confidence. A verdict is rendered only when that confidence clears tau_10pct — the bar chosen so that the answered slice (~10% of queries, n=21 in leave-one-out) carries a measured accuracy of 0.952, with its Wilson interval disclosed rather than hidden. Majority baseline on the pool: 0.647.

Reading an abstain

Since v0.4.0 an abstention is not silence: it names the nearest pool family and its coverage (how many rows, how many positives). That diagnosis is the product — it tells your agent to decide with its own tests, and tells the flywheel where the pool is thin.

# { "decision": "abstain",
#   "family": { "nearest_family": "…", "coverage": { "n": 6, "positives": 2 } },
#   "call_id": "…" }        your tests decide; report the outcome anyway

Audit it yourself

The artifacts are content in the repo, not claims on a page:

$ git clone https://github.com/Denis-hamon/Ghost && cd Ghost
$ cat artifacts/risk-scan-v8-calibration.json
$ cat artifacts/predictor-mcp-calibration.json

The served pool itself (v12, n=430) is produced and governed by the Latent Imagination measurement project; the corpus release is on Zenodo (10.5281/zenodo.21837153).
