GHOST / self-hosting

Self-host the ghost in minutes.

GHOST speaks MCP — any client with a server list can use it. Two transports: remote HTTP (weights + pool stay on the serving host) or local stdio (colocated, needs torch + transformers).

Remote HTTP — recommended

One URL is all the client needs.

# Claude Code
claude mcp add --transport http ghost http://<host>:8093/mcp

# opencode / Cursor / Cline / any MCP client
{ "mcpServers": { "ghost": { "url": "http://<host>:8093/mcp" } } }

Bearer token — fail-closed

Set GHOST_TOKEN on the server to require Authorization: Bearer <token>. The server refuses to boot if the token is set but cannot be enforced (fail-closed). Without a token, serve on an internal network only.

Local stdio — colocated

Zero network; the client spawns the process.

{ "mcpServers": { "ghost": {
  "command": ".venv/bin/python",
  "args": ["server/ghost_server.py"]
} } }

Env overrides

variablerole
LI_POOL_JSON · LI_POOL_NPZserved pool (rows + embeddings)
LI_RISK_CALIBserving calibration (risk-scan regime)
LI_CALIBRATIONgold-axis calibration (assess_patch)
LI_LOG_PATHtelemetry journal (scans + grounded outcomes)
GHOST_HOST · GHOST_PORTHTTP bind (default :8093)
GHOST_TOKENbearer auth, fail-closed

Pool files (latent-pool-*.json/.npz) are deployment artifacts and are not committed — point LI_POOL_JSON/LI_POOL_NPZ at your copy.

Run it

$ git clone https://github.com/Denis-hamon/Ghost && cd Ghost
$ pip install -r requirements.txt
$ python server/ghost_http_server.py
# [ghost] serving http://0.0.0.0:8093/mcp (pool latent-pool-v12.json, stateless)

Weights, pool and calibration are loaded before serving, so the first call pays no cold-start latency.

Repository layout

server/     ghost_server.py (stdio) + ghost_http_server.py (HTTP, mcp-2.0)
artifacts/  risk-scan-v8-calibration.json · predictor-mcp-calibration.json

data/       pool files go here on the serving host (not shipped)
